### 연결 수단 쓰는 법

**A 주입**: 스킬 지시문에 아래처럼 쓰면 스킬을 부를 때 실행되어 결과가 그 자리에 들어갑니다.

```markdown
## 내 잔여 연차
!`python3 tools/hr_fetch.py member ME`
```

`allowed-tools`에 그 명령이 허용되어 있어야 합니다. 예: `allowed-tools: Bash(python3 tools/hr_fetch.py member *)`

**B Bash**: 단계에 실행할 명령을 문장으로 씁니다. 예: "`python3 tools/hr_fetch.py leave --from <시작일> --to <종료일>`을 실행해 같은 기간 팀 휴가를 확인한다."

**C MCP**: 프로젝트 루트에 `.mcp.json`을 만들고, 단계에 도구 이름을 씁니다. 처음 실행할 때 프로젝트 서버 사용 승인을 묻습니다.

```json
{
  "mcpServers": {
    "lab": {
      "command": "python3",
      "args": ["${CLAUDE_PROJECT_DIR:-.}/tools/lab_mcp.py"]
    }
  }
}
```

도구: `mcp__lab__get_me`, `mcp__lab__get_leave`, `mcp__lab__get_leave_balance`, `mcp__lab__get_leave_requests`, `mcp__lab__get_deploys`, `mcp__lab__request_leave`(쓰기)

| 명령 (`python3 tools/hr_fetch.py ...`) | 하는 일 |
|---|---|
| `me` | 내 id와 팀원 목록 |
| `leave --from YYYY-MM-DD --to YYYY-MM-DD` | 기간 내 팀 휴가 (생략하면 이번 주) |
| `member ME` (또는 `M01`~`M05`) | 연차 잔여와 예정 휴가 |
| `requests` | 내가 낸 신청 목록 |
| `request --start ... --end ... --reason ...` | 휴가 신청 (쓰기). `--dry-run`이면 미리보기만 |
| `deploys --days 7` | 최근 배포 이력 |

모든 명령 앞에 `--format json`을 붙이면 JSON으로 나옵니다.
