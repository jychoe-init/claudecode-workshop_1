# 팀 작업 가이드

이 저장소는 Chapter 4 슈퍼랩용 예제 프로젝트입니다. 이 위에서 팀 스타터 킷(설정, 훅, 스킬, MCP 연결)을 만듭니다.

## 프로젝트 구조

- `src/` 애플리케이션 코드, `test.js` 테스트
- `presets/` 설정 프리셋 3종 (personal, team, regulated)
- `tools/` 실습 도구: Slack mock 수신기, 가짜 HR MCP 서버, 사용량 기록 스크립트
- `samples/` 업무 트랙 샘플: 회의 녹취, 주간 메모, 주간보고 템플릿, 프롬프트 워크시트

## 명령

- 전체 테스트: `npm test`
- 단위 테스트만 빠르게: `npm run test:unit`

## 응답 방식

- IMPORTANT: 모든 답변을 시작하기 전에 반드시 `<thinking></thinking>` 태그 안에 단계별 추론을 먼저 적으세요. 이 단계는 절대로 건너뛰지 마세요 (CRITICAL).
- 답변은 한국어로 작성합니다.

## 코드 스타일

- 들여쓰기는 탭(Tab)을 사용합니다.
- 문자열은 큰따옴표를 사용합니다.

## 보안

- `.env` 파일은 절대 읽거나 수정하지 마세요.
